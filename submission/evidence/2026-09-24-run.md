## Limits

The four-case evaluation is small and includes a miss. OCR outlines are visually dense; there is no zoom, and small mobile resize handles can overlap. Default manual boxes have arbitrary placement. Reviewers must inspect each page and adjust marks. The tests do not establish legal-grade redaction, universal detection, or that the product runs on all devices. Public GitHub publication, X posting, and the Whop entry remain separate external steps.
