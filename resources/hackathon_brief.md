# QVAC SDK bounty: submission brief

Source: [Build a local AI app with Tether's QVAC SDK](https://whop.com/qvac/exp_wznos5cmQd7SQY/app/app/posts/post_1Cf6BActRMK2RVY3m4Lqcd/?a=qvacai), checked in the live Whop UI on 24 September 2026. The page showed **Open** and **$17.50**. No submission deadline was displayed in the inspected post; recheck the live status immediately before submitting.

## App requirements

- A working app with `@qvac/sdk` declared at version 0.19.0 or newer.
- Code must call `loadModel` and at least one supported capability, including `ocr` or `completion`.
- AI inference must run on the user's device, without a cloud AI service doing the work. Called functions must exist in the SDK.

## Repository requirements

- Public GitHub repository with an open-source license.
- README with install steps, run steps, and the SDK version.
- At least three commits authored by the builder; original code, not a fork or near-copy of the examples repository and not a duplicate submission.

## Entry requirements

- Screenshot or short screen recording of the running app with AI output visible.
- X post linking the public repository and tagging `@qvac`.
- Submit the public repository URL, X post URL, screenshots or recordings, and one or two lines describing the app and QVAC function calls. An optional line can explain why it was built.

The final Whop entry is reserved for the user's review and action.
